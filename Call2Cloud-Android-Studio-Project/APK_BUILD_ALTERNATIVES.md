# Call2Cloud: 5 Ways to Get the APK

1. Option 1: On Your Android Phone directly using AndroidIDE (No PC or GitHub needed).
2. Option 2: Online in Chrome via Google Project IDX (https://idx.dev).
3. Option 3: Fixed GitHub Actions (.github/workflows/build-apk.yml) with automatic Gradle 8.7 installation.
4. Option 4: Codemagic Cloud CI (1-click Android build).
5. Option 5: Android Studio on PC/Laptop (opening 'android/' subfolder).
